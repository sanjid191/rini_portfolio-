# Raisa Jahan Rini - CSE Portfolio Website 🎓💻

A modern, responsive, high-aesthetic portfolio website for **Raisa Jahan Rini**, a Final Semester Computer Science & Engineering (CSE) student, Full-Stack Web Developer (React.js & Node.js), and SQA & AI Capstone Researcher.

Built using **Vanilla JavaScript (ES6+)**, **HTML5**, and **Vanilla CSS3** with dark/light theme switching, glassmorphism UI, interactive code sandbox CLI, and project filtering.

---

## ✨ Features

- 🌓 **Dark & Light Mode Toggle**: Smooth theme switcher with preference saved in `localStorage`.
- ⚡ **Hero Section**: Custom developer avatar, typewriter role animation, and highlight tags for React.js, Node.js & SQA skills.
- 🔬 **Academic & Capstone Highlight**: CSE undergraduate coursework, Dean's List honors, and AI Medical Vision thesis details.
- 🛠️ **Interactive Skill Stack**: Categorized skills (Languages, Web, AI, Tools & SQA) with animated level bars.
- 💻 **Filterable Projects Showcase**: Filter by Capstone & AI, Full-Stack Web, or Systems & Algo, with detailed interactive modals.
- 🐚 **Interactive Terminal & CLI Sandbox**: Embedded code viewer (`Solution.cpp`, `PortfolioApp.js`, `CapstoneAI.py`) and command-line shell supporting `help`, `about`, `skills`, `projects`, `cgpa`, `resume`, `contact`.
- 📄 **CV Resume Viewer Modal**: In-browser formatted CV preview with download trigger.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile browsers with backdrop-blur navigation drawer.

---

## 🛠️ Built With

- **Structure**: HTML5

## 🚀 Local Setup & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sanjid191/rini_portfolio-.git
   cd rini_portfolio-
   ```

2. **Open in Browser:**
   Simply double click `index.html` or serve with any static web server:
   ```bash
   npx serve .
   # OR
   python -m http.server 8080
   ```
